# Aryaman Awasthi - Portfolio

A terminal-inspired personal portfolio built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS** - green-on-black CRT aesthetic, bento-grid sections, and JetBrains Mono throughout.

## Quick start

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.

> The first run downloads the Google Font (JetBrains Mono) via `next/font`,
> so you need an internet connection on the first build.

## Production build

```bash
npm run build
npm run start
```
